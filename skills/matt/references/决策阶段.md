# 决策阶段

主 agent 在主对话中与用户讨论待定问题。可以查阅代码和文档以核实事实。功能实现及其委派留到决策结束后，由主流程根据用户目标安排。

## 选择访谈技能

以目标项目根目录是否存在 `GLOSSARY.md` 文件作为初始化标记。

- 文件存在时，读取并使用 `grill-with-docs`，按项目约定记录本次议定的术语和需要留档的决策。用户明确要求只读时，将建议的文档修改列在回复中。
- 文件不存在时，读取并使用 `grill-me`，在对话中记录结论。

## 讨论与收尾

围绕影响用户可见行为、范围或验收的取舍，用具体例子说明选项和推荐理由，逐轮等待用户回复。讨论收敛后概括议定方案，请用户确认；有修正时先更新结论。

使用 `grill-with-docs` 时，阶段结束后分别汇报**术语表**和**决策记录（ADR）**的实际修改。指出本次变更的文件、术语或决策以及主要变化。某类文档没有修改时注明“无变更”，待采纳的建议单列。
