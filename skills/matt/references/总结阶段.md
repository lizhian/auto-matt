# 总结阶段

先说明本次需求交付了什么、验收与收敛的结果，以及仍待处理的事项。写明全程墙钟耗时（含等待用户的时间）和去重后的子 agent 数量。

## 主 agent 与子 agent 明细

每个实际参与的 agent 一行，包含主 agent 和嵌套子 agent。同一 agent 返工或复审时，在原行分段记录。列出实际执行的技能，直接完成任务时填“无”。

| Agent | 委派者 | 实际技能 | 工作及结果 | 起止时间 | 耗时 |
| --- | --- | --- | --- | --- | --- |

标明时区。只有派发和收到结果的时间时，将区间标为“委派至回报”。缺失的时间填“未记录”。主 agent 的全程跨度包含等待和并行工作，分别列出有记录的执行区间。并行时长按各自区间展示，全程耗时取实际开始至交付的时间差。

## 流程图和甘特图

- **流程图**按实际执行顺序编号，标明执行者、技能和关键结果，画出发生过的用户决策、并行委派、返工和复审。名称与明细表一致。
- **甘特图**以同一时间轴展示主 agent 与各子 agent 的已知区间，保留并行重叠，同一 agent 再次执行时另画一段。标出缺少时间记录的环节。全部区间缺失时，在甘特图位置说明原因，不估算时长。

## 建议

根据本次实际结果给出可执行的建议，每条说明观察到的问题及建议采取的动作。优先关注验收缺口、重复工作、返工或耗时原因。证据不足以支持具体改进时写明“本次无明确改进建议”。
